## How it works for a participant
1. Choose language: English, हिंदी, मराठी. Can be switched at any time, even mid-quiz.
2. Name, 10 digit mobile number, pick Quiz 1 or Quiz 2, read the rules, Start.
3. 15 minute timer, kept by the server. Closing the page does not stop it.
4. One question at a time, options shuffled for each person (same order after a refresh). ★ marks safety questions.
5. Choosing an answer locks it. Then the page shows right or wrong, the "why" and the manual section.
6. After the last question: score, which ★ questions were missed ("your trainer will call you within 2 days"), a review list, and the task with a WhatsApp button to the trainer (9167954430).

## Rules enforced by the server
- One attempt per phone number per quiz. Entering the same number again (any phone, any browser) resumes the running quiz with the time left, or shows the result if it is finished or timed out. It cannot be restarted.
- Answers and explanations are not in the page. They come from the server only after an answer is saved.
- After 15 minutes (plus 15 seconds grace) no more answers are accepted and the attempt is marked Timed out.

## Airtable: Quiz Attempts table (tblcpS9xrANciDtX3)
One row per person per quiz: Attempt, Participant Name, Phone, Quiz, Language, Status (In progress, Finished, Timed out), Started At, Finished At, Score, Out Of, Star Missed (question numbers), Needs Call (ticked when any ★ is missed), Answers (readable list such as "2 ★: B (wrong, answer C)"), Answer Data (raw), Key (internal).
Letters in the Answers column are the letters in the original draft, not the shuffled letters a participant saw.

To let someone retake a quiz, delete their row.

## Before using it with participants
- Hindi and Marathi were translated by Claude. Have a native speaker read them.
- Q4 and Q8 (Quiz 1) and several Quiz 2 questions have no "why" in the draft, so only the manual section shows.
- Check the website's Airtable token can write to Quiz Attempts (it has only been used to read so far). If it cannot, the Start button shows "Could not connect" and the token needs write access to this table.
